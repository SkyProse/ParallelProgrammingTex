# ParallelProgrammingTex · Concurrency Theatre

## Integrated sources - 24 October 2026

This branch combines the complete English upstream (26 February 2020), an exact
152-file Russian snapshot (5 November 2021), and the existing Concurrency Theatre.
OpenCL and concurrency errors were **renumbered, not missing**. Profiling, Intel
IPP and POSIX Threads are restored without duplicating those chapters; labs 5/6
and the bibliography are active again. The Russian additions also retain the
credit to D. A. Pushkarev.

See [the integration audit](docs/INTEGRATION.md), [source pins](upstreams.lock.json)
and [preserved editions](editions/README.md). The root `main.pdf` is historical;
new books are produced under `build/en/` and `build/ru/`:

```sh
node --test web/tests/*.test.js tests/*.test.js
python3 scripts/build_books.py
```

The corrected native Pthreads example is `native/pthreads_add.c`, not the
unmodified archival `listings/WithPosix.c`. Historical defects and build-only
transformations are documented rather than silently hidden.

Университетский учебник о параллельном программировании и его интерактивный спутник: **остановите исполнение, выберите следующий поток и проверьте, что именно изменило результат**.

Текст пособия и исторические C++-листинги сохранены. Датированные уточнения 2026 года, аудит примеров и новая глава объясняют границы учебных моделей и современные возможности браузера. Исходная ревизия: `1c53d6eb08a7d0041a6f54728b6ba90a59507454`, 19 февраля 2020 года.

## Шесть лабораторий

| Лаборатория | Что можно сделать | Вид данных |
| --- | --- | --- |
| Развилка времени | Создать deadlock, перемотать, выбрать другой поток, изменить порядок замков, исследовать все 23 / 20 состояния | Конечная модель |
| Контракт гонки | Потерять обновление, сравнить atomic и snapshot, проверить сохранение задачи | Явная SC-модель; не перечисление C++ UB |
| Микроскоп памяти | Менять AoS / SoA / padding и размер линии, сравнивать адреса, инвалидации и цену размещения | MSI-подобная учебная модель |
| Эстафета CAS | Соревноваться за `next`, помогать отставшему хвосту, исследовать `expected` и weak spurious failure | Ограниченная append-only очередь |
| Ткацкий станок GPU | Прочитать реальные global / local / workgroup и доступные subgroup ID, задать subgroup size при поддержке | Настоящий WebGPU dispatch |
| Обсерватория | Сравнить одно проверенное вычисление в JS / Workers / WebGPU; импортировать C++ / OpenMP | Реальные замеры с сырыми выборками |

В каждой учебной сцене есть два задания: объяснение собственного решения и перенос знания в новую ситуацию. Прогресс хранится локально в браузере. Записи моделей экспортируются в JSON, проверяются при импорте и воспроизводятся с начального состояния. Импортированные замеры всегда помечены отдельно.

## Запуск

### Графическая редакция 1.1

У каждой сцены теперь есть ракурсы **«Общий план / Сверху / Ближе»**, качество
**«Авто / Экономно / Чётко»** и развёрнутый режим лаборатории. Выбор камеры и
качества сохраняет логическое время. В графе замков подсвечивается пройденная
ветка; материалы используют общий TSL-контур, работающий через WebGPU и WebGL 2.

Ячейки памяти и GPU-вызовы можно выбирать на сцене либо через доступные поля
справа. Карточка объясняет адрес, соседей в кеш-линии или точные ID dispatch.
Импорт остаётся помеченным как импорт, схема до запуска — как схема.

Потеря графического контекста переключает сцену на SVG/текст с сохранением
исполнения. После восстановления контекста показывается текущее состояние,
включая шаги, выполненные во время сбоя. Ресурсы переиспользуются, размер
framebuffer ограничен; в покое и во время измерений рендер не крутится постоянно.

Подробности реализации, ограничения и первичные источники:
[графика и восстановление](docs/RENDERING.md).

### Локальная сборка

Требуется Node.js 22+; проверено на Node.js 24. Зависимости зафиксированы в lockfile.

```sh
cd web
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

Открыть `http://localhost:5173`. Сборка находится в `web/dist/`: её можно разместить на обычном статическом хостинге. Все скрипты и Three.js поставляются вместе с приложением; внешнего CDN во время работы нет.

Для этой редакции перед установкой зависимостей выберите ветку
`feature/theatre-webgl-finale`. Она продолжает интегрированную редакцию
`integration/upstreams-and-theatre-2026`; исходные ветки и архивные материалы
остаются доступны отдельно.

WebGPU требует безопасного контекста (HTTPS или localhost) и доступного адаптера. Отрисовка использует Three.js 0.186.1 `WebGPURenderer`, TSL и WebGL 2 fallback. При недоступности обоих графических API остаются интерактивная SVG-сцена, текстовая партитура и граф состояний. `?renderer=webgl` принудительно выбирает графический WebGL 2 путь для проверки.

Клавиатура: **1 / 2** — шаг T0 / T1, **← / →** — перемотка и следующий шаг, **пробел** — автоматическое расписание, **R** — начало записи. Обычные кнопки выполняют те же действия. Камера не меняет логическое время.

## Тесты

Реализация развивалась через RED → GREEN: сначала проверки моделей, кодеков, контроллера и вычислений, затем код. Полный перебор проверяет конкретный конечный автомат, не произвольную C++-программу.

```sh
# Из корня: модели, учебные материалы, импорт и настоящая компиляция OpenMP
node --test --test-isolation=none web/tests/*.test.js tests/native*.test.js

# Браузерная интеграция (после npm ci и сборки)
cd web
npx playwright install chromium
npx playwright test
```

GitHub Actions запускает оба уровня, сохраняет результаты, скриншоты и отчёты. Графический CI использует программный адаптер; такие результаты не характеризуют скорость реального GPU. Отдельная проверка GPU явно пропускается, если адаптер недоступен, и не объявляется успешно измеренным экспериментом.

## Нативные измерения

```sh
bash native/run.sh --size 262144 --threads 4 --repetitions 7 > native-results.json
bash native/run.sh --false-sharing --iterations 500000 --threads 4 --line-bytes 64 --repetitions 7 > native-sharing.json
```

Требуется C++17-компилятор с OpenMP. JSON можно открыть через «Импорт». Нативная программа измеряет собственную область исполнения; её числа не смешиваются с браузерным end-to-end временем как равнозначные. Подробнее: [native/README.md](native/README.md).

В браузерном стенде одинаковы вход, uint32-преобразование и модульная редукция. После каждого запуска проверяются все элементы и сумма. Графика остановлена на время измерений. Первый запуск с подготовкой, повторные наблюдения и optional GPU-pass timestamp учитываются отдельно. 95% интервал Student-t относится к среднему, медиана приведена отдельно. Это исследовательские замеры конкретного устройства, не универсальный рейтинг.

OpenMP 6.0 — финальная спецификация; OpenMP 6.1 TR15 на дату аудита остаётся Public Comment Draft. Версия стандарта не означает полной поддержки компилятором. Subgroup-size-control используется только при обнаружении; buffer_view, immediates и HTML-in-Canvas показаны как диагностируемые optional / экспериментальные возможности, а не обязательная основа приложения.
