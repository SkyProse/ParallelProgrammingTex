# Preserved source editions

`ru/` is the complete, unmodified tracked tree of
`shilko2013/ParallelProgrammingTex` at
`53535f92db505a5d0442dca5a3918fe3ea78189a` (2021-11-05).

All 152 tracked files are retained, including historical PDFs and auxiliary
files. Do not compile inside this directory: generated files would invalidate
the exact-tree check. `python3 scripts/build_books.py --edition ru` creates a
disposable build copy instead. Its PDF is a new typesetting of historical text,
not a claim that the historical examples have all been corrected.

The active integrated English edition remains at the repository root. Its
original source revision and the Russian-to-English chapter mapping are pinned
in `../upstreams.lock.json`. See `../docs/INTEGRATION.md` for merge decisions,
authorship, historical defects and reproducible verification commands.
